一、这个软件是做什么的
----------------------------------------------------------------------
JM 下载助手 是一个跑在你自己电脑上的「本地网页版下载工具」。

它的用途很简单：
    输入一个本子编号 → 自动下载整本 → 合并成一个 PDF 存到本地，
    并把下载记录留下来，可以随时查看、搜索、打开、收藏、删除。

特点：
    · 全程在浏览器里操作，界面美观，鼠标点点就行
    · 下载过程有实时进度条：已下多少张、第几章、正在合并 PDF
    · 下载完自动合并成 PDF，不会留一堆散图
    · 内置记录管理：谁下过、什么时候下的，一目了然，可按编号搜索
    · 支持收藏夹：喜欢的本子一键收藏（只记文件名，不复制文件，不占双份空间）
    · 支持改目录：下载目录、收藏目录随时可换，旧内容自动搬过去
    · 可填 AVS 登录：能下载到少数「登录后才可见」的内容
    · 可检查更新：一键对比 GitHub 上的最新版本
    · 升级不用卸载：新版安装程序会保留你的漫画、收藏和设置
    · 完全本机运行，不对外开放任何网络服务，别人访问不到


二、怎么安装
----------------------------------------------------------------------
【方式一：安装程序（推荐，换个电脑也能用）】

    1. 拿到 JM下载助手-安装程序.exe（约 93 MB，单文件）
    2. 双击运行，会弹出「安装向导」，让你选三个位置：
         · 安装位置    —— 程序本体装到哪里（默认 D:\JM下载助手）
         · 下载目录    —— 下载的漫画 PDF 和记录日志存哪里
         · 收藏夹目录  —— 收藏日志 jm_fav_log.txt 存哪里（不再复制漫画）
       三个位置都可以点「浏览…」自己选，建议放在 D 盘等数据盘，
       不要放进 C:\Program Files（那里需要管理员权限）。
    3. 下面还有两个勾选项：
         [√] 在桌面创建快捷方式
         [√] 安装完成后立即启动
    4. 点「开始安装」，几秒钟即可完成。装完桌面会出现快捷方式。

    注意：程序自带 Python 运行环境，目标电脑不需要装 Python，
          也不需要联网下载任何依赖。

【方式二：绿色版（免安装）】

    把整个「JM下载助手」文件夹（约 126 MB）拷到任意位置，
    双击里面的 JM下载助手.exe 即可。
    首次运行会弹出设置窗口，同样让你选下载目录和收藏夹目录。

    注意：绿色版必须整个文件夹一起拷，
          只拷 exe 是不行的（它旁边的 _internal 文件夹里有运行环境）。

【升级（已经装过旧版本）】

    不用先卸载！直接双击新版安装程序即可。

    窗口会显示「检测到已安装 v1.0，将更新到 v1.1」，
    并把三个路径全部自动填好、锁定不可改。点「立即更新」，
    只替换程序本体，下面这些全部原样保留：
        · 全部漫画 PDF 与下载记录
        · 收藏夹内容与收藏记录
        · 下载目录 / 收藏目录的设置
        · 填好的 AVS

    如果确实想换位置，点窗口下方的「改为全新安装」即可解锁路径输入，
    此时也只是覆盖程序文件，不会删除任何漫画。


三、怎么启动、怎么停止
----------------------------------------------------------------------
启动：
    双击桌面上的「JM 下载助手」快捷方式（或绿色版文件夹里的 exe）

    程序会做两件事：
      1. 弹出一个小黑窗口 —— 那是程序本体，显示运行状态
      2. 自动打开浏览器，进入操作界面

停止：
    直接关闭那个黑窗口即可。
    黑窗口最小化 = 服务继续在后台运行，不影响使用。

访问地址（也可以手动在浏览器输入）：
    http://127.0.0.1:8080

若服务已经在运行，再双击一次快捷方式，只会打开浏览器，
不会重复启动第二个程序。


四、界面总览
----------------------------------------------------------------------
整个界面分三块：

    左侧栏   导航（下载 / 收藏 / 设置）+ 底部的目录信息与磁盘占用条
    顶部栏   当前目录路径、访问地址（点击可复制）、浅色/深色主题切换
    主区域   随左侧导航切换的三个页面

主题：右上角按钮可切换「浅色 / 深色」，选择会被记住。


五、下载页 —— 怎么下载、怎么看记录
----------------------------------------------------------------------
【左上：下载任务】

    编号（纯数字） + [下载] 按钮
        输入本子编号，点下载或按回车。下载进行中，输入框与按钮会锁定。

    状态
        空闲 / 程序运行中（带转圈）/ 已完成 / 上次任务失败

    进度条
        状态下面有一条进度条，实时显示：
            · 百分比与「已下载 12 / 27 张」
            · 当前在第几章、章节标题（例如 第 1/1 章 · 某某标题）
            · 三个阶段的文字提示：
                  正在获取本子信息… → 正在下载… → 正在合并为 PDF…
        刚开始几秒还没有总数，进度条会来回滑动，表示正在请求信息。
        整本下完、PDF 合并完成后，进度条变绿显示 100%。

    搜索下载记录 + [搜索]
        按编号搜索，只查最近 500 条记录

    [显示全部]
        清空搜索条件，恢复完整列表

    [搜索全部]
        按编号扫描全部记录，记录多时耗时更久

    运行日志（可折叠）
        实时显示下载器的原始输出，下载失败的原因就在这里

    [打开下载文件夹]
        用资源管理器打开当前下载目录

【右上：下载记录】

    最新记录在最上面，底部显示「共 N 条记录」
    每 1.5 秒自动同步一次状态；下载完成会自动刷新并弹出提示

    每条记录从头到尾有三处可点：

        ★（最左）  空心 = 未收藏，点击 → 在收藏目录的日志里记一行文件名，
                   图标变实心（不会复制 PDF，不占额外空间）；
                   已实心时再点 = 取消收藏（只抹日志，原文件不受影响）。
                   操作前会弹确认框。

        中间主体   单击 → 用系统默认程序打开这个 PDF

        🗑（最右） 删除该 PDF 文件，并从 jm_log.txt 里抹去对应记录。
                   会先弹确认框写明后果，不可撤销。

    [刷新数据]
        重新读取日志文件（你在外部改过 txt 之后点它）

    说明：一个本子在日志里本来有两行（标题行 + .pdf 行），
          界面已自动合并，所以同一条记录只会出现一次。
          如果文件在目录里找不到（比如被手动移走），
          该条会显示「文件缺失」标记，仍然可以删除记录。


六、收藏页 —— 收藏夹管理
----------------------------------------------------------------------
    收藏夹目录默认是安装时选的那个（例如 D:\JM下载助手\收藏）
    注意：收藏只记录文件名，PDF 本体仍在下载目录；
          收藏页里的「打开」也是去下载目录取文件。

    功能与下载页基本一致：
        · 按编号搜索 / 显示全部 / 搜索全部
        · 单击记录打开 PDF
        · 最左侧的星恒为实心 —— 点击即「取消收藏」（从收藏夹删除文件
          并抹去记录）
        · 最右侧垃圾桶 —— 删除文件并抹去记录
        · [刷新数据] 重新读取收藏日志

    特别说明：收藏夹里原本就已经存在的漫画，会自动登记进日志
              （编号一栏显示为灰色的「-」），所以旧收藏也能在这里
              查看和搜索，不需要你手工整理。


七、设置页 —— 改目录、看占用
----------------------------------------------------------------------
【左：目录设置】

    下载目录       PDF 成品与 jm_log.txt 存放位置
    收藏目录       收藏副本与 jm_fav_log.txt 存放位置

    [保存并迁移内容]
        保存新路径，并把原目录里的所有文件与子文件夹
        「整体搬」到新位置。规则如下：
            · 只处理真正发生变化的那一项，没变的不动
            · 新目录不存在会自动创建
            · 新目录里已有同名文件时跳过，不覆盖
            · 搬完后旧目录若已空，会自动删除
            · 拒绝相对路径，也拒绝新旧目录互相包含
        同一磁盘内是瞬间改名；跨磁盘会先复制再删除，
        文件多时需要等一会儿，页面会显示「正在迁移…」。

    [恢复默认路径]
        把输入框填回默认值（还要再点保存才会生效）

【右：磁盘占用】

    分别显示下载目录、收藏目录占用了多少，
    以及所在磁盘的总容量、已用、可用。

    [重新统计]
        重新扫描一遍（目录很大时会有短暂等待）

【左下：AVS 登录（可选）】

    平时不用管，留空就行。
    只有遇到「该漫画只对登录用户可见」这类提示时才需要填。

    怎么拿到 AVS：
        1. 用浏览器登录禁漫网站
        2. 按 F12 打开开发者工具
        3. 找 Application（应用） → Cookies → 点开该网站
        4. 找到名字叫 AVS 的那一项，复制它的值
        5. 粘到这里的输入框，点 [保存 AVS]

    保存后右上角会显示绿色「已配置」。下次下载就会带上登录凭证。
    AVS 只保存在本机的 settings.json 里，不会上传到任何地方。
    想恢复成不登录状态，点 [清空] 即可（已下载的文件不受影响）。

【右下：关于与更新】

    显示当前版本号（例如 v1.1）。

    [打开项目主页]
        在浏览器里打开本项目的 GitHub 页面

    [检查更新]
        联网读取 GitHub 上的最新版本号，并告诉你：
            · 已是最新版本 → 绿色提示
            · 发现新版本   → 显示版本号、发布时间、更新说明，
                            并给出「前往发布页」和「下载安装程序」按钮
        检查更新只比对版本号，不会自动下载、也不会改动任何文件。

    升级方法见第二章最后的「升级」一节：下载新版安装程序直接运行即可。


八、侧栏的磁盘占用条
----------------------------------------------------------------------
    侧栏左下角，「下载目录」「收藏目录」下方各有一条彩色横条，
    三段颜色分别代表：

        橙色 = 该目录（下载 / 收藏）占用的空间
        紫色 = 同一磁盘上其它内容占用的空间
        灰色 = 该磁盘还剩多少可用空间

    平时是细细的一条；鼠标放上去会「展开」成一条大的指示条，
    并显示具体数字，例如：
        占用 8.61 GB · 其它 833.2 GB · 可用 571.2 GB / 共 1.38 TB

    因为下载目录在整块磁盘里占比通常很小，橙色往往只是很细的一段，
    这是正常的。


九、文件都存在哪
----------------------------------------------------------------------
    安装目录（你安装时选的）
        JM下载助手.exe      主程序
        _internal\          运行环境，不要删
        settings.json       你的目录设置与 AVS
        option.yml          下载参数（域名、PDF 输出）
        downloads\          下载时的临时图片工作区，合并成 PDF 后自动清空
        卸载.cmd            双击即可卸载
        使用说明.txt        本说明的简版

    下载目录（可改）
        漫画 PDF 文件
        jm_log.txt          下载记录日志

    收藏目录（可改）
        收藏的 PDF 副本
        jm_fav_log.txt      收藏记录日志


十、下载到 PDF 的过程
----------------------------------------------------------------------
    1. 你在网页输入编号并点下载
    2. 程序通过移动端接口抓取该本子的图片，先存到 downloads\ 工作区
    3. 整本下完后自动合并为一个 PDF，输出到下载目录，文件名 = 本子标题
    4. 合并成功后自动删除原始图片并清理空目录
       —— 所以下载目录里只有干净的 PDF，没有一堆散图


十一、记录日志的格式
----------------------------------------------------------------------
    日志是纯文本（UTF-8），每行三列，用「 | 」分隔：

        350234 | 董卓 上+下 | 2026-10-13 22:41:46
        350234 | 董卓 上+下.pdf | 2026-10-13 22:41:46

    下载成功时写入两行（共用同一个时间戳），界面显示时合并为一条。
    删除记录时，两行会一起被抹去。
    你可以用记事本直接打开查看或编辑，改完回网页点「刷新数据」即可。


十二、常见问题
----------------------------------------------------------------------
★ Q：桌面上的「JM 下载助手」快捷方式双击打不开，或提示找不到文件？
A：请先确认安装目录里确实有「JM下载助手.exe」这个名字。

   1.1 版起安装程序已经修正了快捷方式的目标路径，正常安装不会再出现
   这个问题。如果你是从 1.0 升级上来的旧快捷方式，删掉它，
   再右键安装目录里的「JM下载助手.exe」→ 发送到 → 桌面快捷方式
   重建一个即可。

   如果你后来手动移动或重命名过安装目录，任何快捷方式都会失效，
   同样按上面的方法重建。

Q：双击 exe 没反应？
A：先看有没有黑色窗口弹出来。如果窗口一闪就没，多半是所在路径
   有特殊字符，把整个文件夹移到简单路径（例如 D:\JM下载助手）再试。

Q：浏览器提示「无法访问此网站」？
A：服务可能还没起来，等 2~3 秒刷新。仍然不行就看黑窗口里的提示。

Q：提示端口被占用？
A：说明已经有一个 JM 下载助手在跑了，去任务栏找那个黑窗口即可。

Q：杀毒软件报警？
A：这类打包程序经常被误报。添加信任或选择「仍要运行」即可。
   程序只在你本机运行，不对外提供服务，也不上传任何东西。

Q：下载失败，提示「该漫画只对登录用户可见」？
A：少数本子需要登录状态。不用改配置文件了，直接在网页里操作：

      设置页 → 左下「AVS 登录（可选）」→ 粘贴 AVS 值 → [保存 AVS]

   AVS 从浏览器里已登录的禁漫网站获取（浏览器 → F12 → 应用 →
   Cookies → 找到 AVS 复制值）。保存后右上角显示「已配置」即生效，
   再重新下载即可。填错了就点 [清空] 恢复。

Q：怎么知道有没有新版本？
A：设置页 → 右下「关于与更新」→ [检查更新]。
   有新版会给出「前往发布页 / 下载安装程序」按钮，下载后直接运行安装程序
   即可升级，不需要先卸载，漫画与设置全部保留。

Q：我要换一台电脑，怎么迁移？
A：把安装目录整个拷过去即可（或者用安装程序在新电脑重装一次）。
   如果想连漫画一起搬，把「下载目录」和「收藏目录」也拷过去，
   换电脑后第一次启动时，在设置页把这两个目录指向拷贝过来的位置。
   注意：日志就放在这两个目录里，所以记录和收藏会跟着一起过去。

Q：怎么卸载？
A：安装版有三种方式，任选其一：
     1. 打开 Windows「设置 → 应用 → 已安装的应用」，
        找到「JM 下载助手」，点「卸载」
     2. 双击安装目录里的「卸载.cmd」
     3. 手动删掉安装目录和桌面快捷方式

   前两种方式会弹出确认窗口，并问你要不要一起删数据：

        [ ] 同时删除下载目录与收藏夹里的漫画和日志

     · 不勾选（默认）→ 只删程序。漫画 PDF、收藏、日志全部原样保留，
                        以后重装同一个位置，记录和收藏直接接着用
     · 勾选         → 连漫画和记录一起清掉，不可恢复

   绿色版：直接删掉整个文件夹即可。

   说明：安装时会在「当前用户」下登记一条卸载信息
        （HKCU\...\Uninstall\JM下载助手），所以系统「应用」列表里
        能看到它；卸载后这条登记会自动清除。
        除此之外不写任何注册表、不装系统服务。


十三、v1.2 新增的两个功能
----------------------------------------------------------------------
【输入编号自动识别已下载】

    在下载页输入编号后，程序会自动去下载记录里比对：

        · 没下过 → 状态显示「空闲」，照常点下载
        · 下过   → 状态变成「已下载」，进度条下方出现一张信息卡，
                   显示封面缩略图、编号、标题和下载时间

    这时点「下载」按钮会先问一句「已下载过，是否重新下载」，
    点「重新下载」才会覆盖原文件；点卡片上的「打开这本」可直接看。

    也可以在浏览器地址里带编号直接打开，例如：
        http://127.0.0.1:8080/?id=422869

【清除所有下载数据】

    在「设置」页有一张红色的「清除所有下载数据」卡片：

        · 点一下会连续弹两次确认（第一次说明不可恢复，第二次再问确定）
        · 确认后删除：下载目录里全部 PDF、下载记录、收藏记录、图片工作区
        · 删除后无法找回，也不会进回收站

    清空之后可以照常继续下载，不影响程序本身。


十四、注意事项
----------------------------------------------------------------------
    · 一次只能下一个本子。有任务在运行时再点下载会被拒绝。
    · 删除是永久删除，不进回收站，删文件和删记录都不可撤销。
    · 收藏是「复制」而不是「移动」，同一本会占两份空间。
    · 收藏页只管理收藏目录顶层的 PDF，放在子文件夹里的不会登记。
    · 服务只监听本机（127.0.0.1），手机、别的电脑访问不了；
      也没有密码 —— 这是有意为之，因为只有本机能连。
    · 关闭黑窗口就等于停止服务。
    · 请合理使用，不要一次性批量抓取太多，减轻对方服务器压力。
