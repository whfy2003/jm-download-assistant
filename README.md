# JM 下载助手（本地网页版）

把 [JMComic-Crawler-Python](https://github.com/hect0x7/JMComic-Crawler-Python) 包装成「双击即用」的本地下载工具：
**图形化安装向导 ＋ 网页操作界面 ＋ 自动合并 PDF ＋ 下载记录与收藏管理**。

## 功能一览

**下载页**
- 输入本子编号 → 后台下载 → 自动合并为一个 PDF 存入本地目录
- **实时进度条**：已下载张数 / 总张数、第几章、当前章节名，并单独区分「获取信息 → 下载图片 → 合并 PDF」三个阶段
- **已下载识别**：输入编号后自动比对下载记录，命中则状态显示「已下载」，并在进度条下方显示该漫画的信息卡（PDF 首页缩略图、编号、标题、下载时间），**不会重复下载**；点「重新下载」才会覆盖
- 下载记录读取同目录日志，同一个本子只显示一条（标题行与文件名行自动合并）
- 单击记录用系统默认程序打开 PDF
- 每条记录：★ 收藏 / 🗑 删除文件并从日志抹去记录
- 按编号搜索（最近 500 条 / 全部）、刷新数据、实时状态与运行日志

**收藏页**
- 收藏夹独立日志，支持查看、搜索、打开、取消收藏、删除
- **收藏只记文件名，不复制 PDF**（省一半空间）：收藏后文件仍留在下载目录，收藏页直接去那里取；取消收藏只抹日志，不动原文件
- 旧版本复制到收藏目录里的副本仍然兼容显示，不会被自动删除

**设置页**
- 修改下载目录 / 收藏目录，保存时**自动把原目录内容整体迁移**到新位置
- 迁移规则：只搬变化的项、同名不覆盖、旧目录空后自动删除、拒绝非法路径
- **清除所有下载数据**：删除两个目录里的全部漫画与日志、清空图片工作区；点击后需要**两次确认**，删除后不可恢复
- **AVS 登录（可选）**：填上浏览器登录后的 `AVS` cookie，即可下载登录后才可见的内容；留空则与之前完全一致
- **检查更新**：一键比对 GitHub 上的最新版本，有新版会给出下载入口；也可直接打开项目主页
- 显示两个目录的占用与所在磁盘的总容量 / 已用 / 可用

**升级**
- 新版本安装程序**不需要先卸载旧版**：会识别已安装的版本，只替换程序文件
- 下载目录、收藏目录、`settings.json`（含 AVS）、全部漫画与记录**原样保留**

**界面**
- 与官方 `jm-view-server` 同一套设计令牌（品牌色 `#5b5bd6`、圆角卡片、侧栏 + 顶栏）
- 浅色 / 深色主题一键切换并记住
- 侧栏磁盘占用条：**橙色＝该目录占用 · 紫色＝同盘其它占用 · 灰色＝可用**，鼠标悬停展开显示具体数字

## 快速开始

### 方式一：安装包（推荐，无需 Python 环境）

1. 下载 `JM下载助手-安装程序.exe`（约 93 MB）
2. 双击运行，在向导里选择三个位置：
   - **安装位置**：程序装到哪里（默认 `D:\JM下载助手`）
   - **下载目录**：漫画 PDF 与记录日志存哪里
   - **收藏夹目录**：收藏日志（`jm_fav_log.txt`）存哪里，不再复制漫画
3. 点「开始安装」，几秒完成。之后双击桌面快捷方式即可使用

> 目标电脑**不需要安装 Python**，也不需要联网安装依赖。
> 程序完全本机运行，只监听 `127.0.0.1`，不对外开放任何服务。

**卸载**：Windows「设置 → 应用」里找到「JM 下载助手」卸载，或双击安装目录里的 `卸载.cmd`。
卸载时会询问是否一并删除下载目录与收藏夹的内容（默认不删）。

**升级到新版本**：**不用先卸载**，直接下载新版安装程序运行即可。

安装窗口会提示「检测到已安装 v1.0，将更新到 v1.1」，三个路径自动填好并锁定；
点「立即更新」后只替换程序文件（`JM下载助手.exe` 与 `_internal`），
**下载目录、收藏目录、AVS 设置、全部漫画与记录原样保留**。
如果想换位置，点窗口下方的「改为全新安装」即可解锁路径输入。

> 也可以在网页「设置 → 关于与更新」里点「检查更新」，直接比对 GitHub 上的最新版本。

### 方式二：源码版

```bash
git clone https://github.com/whfy2003/jm-download-assistant.git
cd jm-download-assistant

# 建虚拟环境并安装依赖
python -m venv .venv
.venv\Scripts\python.exe -m pip install -U pip
.venv\Scripts\python.exe -m pip install -e ".\JMComic-Crawler-Python[plugins]"
.venv\Scripts\python.exe -m pip install flask

# 启动
start-jm-web.cmd
```

浏览器访问 http://127.0.0.1:8080

## 已知问题

### 1. 桌面快捷方式

安装程序会按「安装位置」生成桌面快捷方式。如果你**后来手动移动或重命名了安装目录**，
旧快捷方式会失效，请注意：

1. **直接去安装目录里启动**：双击目录里的 `JM下载助手.exe`
2. **手动重建快捷方式**：右键 `JM下载助手.exe` → 发送到 → 桌面快捷方式
3. 也可以打开网页后，在地址栏收藏 `http://127.0.0.1:8080`

> v1.1 起快捷方式的目标路径已按实际安装位置生成，正常安装不会再出现指向错误。

### 2. 上游核心功能的已知限制

以下问题属于上游项目范畴，请查阅[上游文档](https://jmcomic.readthedocs.io/zh-cn/latest/)：

- 网页端接口（`impl: html`）在部分网络环境返回 403（本项目已默认改用移动端 `impl: api`）
- 少数本子提示「只对登录用户可见」，在网页**设置页的「AVS 登录」**里填入浏览器中的 `AVS` cookie 即可
- 域名失效需要等待上游更新
